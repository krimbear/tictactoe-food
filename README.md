# Jungle Words

Откройте `index.html` в современном браузере. Установка и сервер не нужны. Для GitHub Pages загрузите все файлы из этой папки в корень репозитория и включите Pages для выбранной ветки.

Все изображения, стили и код лежат рядом. Внешних библиотек, шрифтов и сетевых запросов нет. Музыка и эффекты синтезируются через Web Audio API и начинают звучать после первого нажатия: браузеры запрещают автоматический запуск звука до действия пользователя. Кнопка звука выключает и музыку, и эффекты.

Игрок всегда ходит первым, случайно получая X или O. Компьютер в 70% случаев выбирает случайную клетку и в 30% использует простую тактику. Повторений слов в партии нет. Максимум потребуется девять заданий: после каждого ответа на поле появляется хотя бы одна фишка.

За победу начисляется `max(0, 1500 − 100 × попытки − 200 × ошибки)` очков. Попытка — один непустой ответ; пустой ввод не расходует ход. При поражении и ничьей — 0 очков. Минимальная победа за три верных ответа даёт 1200 очков.

Exit завершает игру и выключает музыку. Браузер не разрешает надёжно закрыть вкладку, открытую самим пользователем, поэтому после выхода появляется сообщение, что вкладку можно закрыть, и возможность вернуться в меню.

Обезьянка в окнах — кадрированный фрагмент исходного поля. Для инструкции поверх него добавлен жест указательного пальца; для победы — радостная анимация. Это тот же персонаж из предоставленного изображения.

Проверка логики: `node verify.cjs`.
